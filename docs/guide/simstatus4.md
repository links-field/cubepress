# SIM Status 4.0


This chapter describes SIM life cycle stages in 4.0 system.
> **Note:** Not all customers have been migrated to version 4.0. Some accounts may still operate under previous lifecycle logic.

## Overview
In SIM Lifecycle 4.0, the **pre-activation stage** has been refined.  
It is now divided into four sub-stages to provide a more accurate representation of a SIM’s current state.


| Status        | Description           | Billing  |
| ------------- |-------------| -----|
| `Inactive`     | SIM is not active, no data is available. | `not started` |
| `Active-ready`     | SIM is active and can be used. | `not started` |
| `Active-test`     | SIM is running on a test service. | `test package` |

The rest of the stages remain unchanged in terms of their definition and behavior.
