
# Scheduled SMS Service  
> Cube provides a scheduled SMS service that allows you to set up messages to be sent at specified times. It also supports automatic recurring delivery.

![Scheduled SMS](/scheduledsms.png)


## Sending a Scheduled SMS 
 Access the feature:
- Click the SMS menu in the left navigation sidebar.  
- Switch to the Scheduled SMS tab at the top.  
- Click the + New button to create a scheduled SMS.  

## Scheduling options:  
- **Once**: Send at a specific date and time.  
- **Repeated**:  
  - Supports weekly recurrence.  
  - Optional end date for automatic termination.  

### To SIMs:  
- Manually enter or import SIM card numbers (via CSV/XLXS files) .  

### Notifications:  
- Enable email alerts to receive notifications after scheduled SMS execution.  

## Scheduled SMS Delivery Records 
### View records:
- Navigate to the All SMS menu.  
- Filter records by selecting the Scheduled type.
  
::: TIP 
Status column indicates the whether the SMS sent is succesful.
:::
### Execution history:  
- Click on the ID of the Scheduled SMS to view its execution history.
- Display the execution time and status of each scheduled task.
- Shows counts of successful/failed deliveries.
  
::: TIP
If your SMS quota is lower than the scheduled message quantity, no messages in the batch will be sent.
:::
